# Referencia historica sustituida

La regla de version 1.1.1 fue sustituida por [estilo-referencias.md](estilo-referencias.md), que incorpora los cinco MP4 y los dos JSON aprobados por el usuario. Usar siempre la especificacion nueva: Inter, y=11%, texto progresivo, palabras anteriores atenuadas, pulso breve y marco azul selectivo con cuatro puntos.
